How to Split a PDF Online

Learn how to extract selected pages from a PDF, use page ranges, and create a separate document without changing the original file.

Large PDF documents often contain pages you do not need for a particular task. Splitting a PDF lets you extract only the pages that matter and save them as a new document.

Why split a PDF?

Splitting can be useful when a document contains several sections but you only need one part. It can also make a file easier to share when sending the entire original document would be unnecessary.

Common reasons to extract PDF pages

  • Save selected pages from a long report.
  • Extract a specific section from a document.
  • Create a smaller PDF for sharing or uploading.
  • Separate pages needed for an application or submission.
  • Keep only relevant pages from a scanned document.

How to split a PDF with Fixora

  1. Open the Fixora PDF Splitter.
  2. Select the PDF you want to process.
  3. Check the total number of pages detected.
  4. Enter the pages you want to extract.
  5. Start the split operation.
  6. Download the new PDF.

How to enter page numbers and ranges

Fixora accepts individual page numbers and ranges separated by commas. For example:

  • 1 to extract the first page.
  • 1, 3, 8 to extract selected individual pages.
  • 5-9 to extract a continuous range.
  • 1, 4, 7-10 to combine individual pages and a range.

Does the original PDF change?

No. Splitting creates a new PDF containing the pages you selected. Your original PDF remains separate on your device.

What happens if a page is listed twice?

Fixora removes duplicate page numbers automatically when creating the extracted page list. The resulting document contains each selected page once.

Tips before splitting an important document

  • Check the page count before entering ranges.
  • Review the page numbers carefully.
  • Keep the original file as a backup.
  • Open the downloaded result to confirm the expected pages are present.

Frequently asked questions

Can I extract several page ranges at once?

Yes. You can combine page numbers and ranges in one entry, such as 1, 3, 5-7.

Can I extract one page?

Yes. Enter the page number, such as 4, to create a PDF containing that page.

Will the page order be preserved?

The selected page numbers are processed in ascending order, so the resulting PDF follows the order of the selected pages.

Is the original file deleted?

No. The splitter creates a new PDF and does not replace your original file.
